# Prospecção Digital — LinkedIn e Instagram DM

> Mandar ANTES de ir presencialmente. O dono abre, vê o problema dele, aí quando
> você chega ele já sabe o que você faz.

---

## FLUXO

```
1. Prospecar no Google Maps → achar negócio com GMB fraco
2. Fazer Raio-X (5 min)
3. Montar mensagem personalizada
4. Mandar no LinkedIn OU Instagram
5. Esperar 24-48h
6. Se responder → agenda visita
7. Se não responder → visita presencial com Raio-X pronto
```

**Regra:** A mensagem digital é o ISQUEIRO. A venda é presencial.

---

## TEMPLATE 1 — LinkedIn (dono/profissional)

### Assunto:
```
Google do [Nome do Negócio] — rápida observação
```

### Mensagem:
```
Oi [Nome], tudo bem?

Sou Guilherme, trabalho com presença digital pra negócios locais
aqui de [Cidade].

Passei pelo teu [Google/business name] e notei uma coisa que
pode estar te custando cliente sem tu saber.

Posso te mostrar rapidinho? São 30 segundos.
```

### Se responder "pode":
```
Beleza. Olha só:

[Link da landing page OU print do Raio-X]

Seu Google tem [problema específico: poucas fotos / sem avaliações /
informação incompleta]. Isso faz com que quem te procura no Google
acabe indo pro concorrente.

Resolver isso é simples — leva 2-5 dias e custa entre R$297 e R$497.

Quer que eu te mostre presencialmente? Posso passar aí [dia/hora].
```

### Se não responder em 48h:
```
Fala [Nome], só queria saber se chegou a ver. Se não fizer
sentido, sem problema! Só queria ajudar.
```

## TEMPLATE 2 — Instagram DM (negócio local)

### Para negócio COM perfil ativo:
```
Fala! Vi o Instagram de vocês, tá muito bom. Mas olhei o Google
e tem uma coisa que pode estar fugindo: [problema específico].

Fiz uma análise rápida, posso te mandar?
```

### Para negócio COM perfil fraco/parado:
```
Oi! Passando aqui porque trabalho com negócios locais de
[Cidade]. Vi que o Google de vocês tá [incompleto/sem fotos/
sem avaliação].

Isso faz diferença na hora do cliente escolher. Posso te
mostrar como resolver?
```

### Se responder:
```
[manda o Raio-X ou link da landing page]

Olha só. Seu Google tem [X]. O concorrente tem [Y]. Quem
pesquisa no Google e não te encontra, vai pra ele.

Posso passar aí pra gente conversar 5 minutos? Sem compromisso.
```

## TEMPLATE 3 — WhatsApp (quando tem o número)

pra negócios aqui de [Cidade].

Passei pelo teu [Google] e vi uma coisa que pode estar te custando
cliente. Posso te mostrar rapidinho?

### Se responder:
```

primeiro... e olha o teu. Isso é dinheiro saindo.

Posso resolver isso por R$397-497, configurado em 2-5 dias.
Topa ver presencialmente?
```
