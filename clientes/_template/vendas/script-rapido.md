# Script Rápido — 1 página

> Imprime. Leva no bolso. Consulta entre visitas.

---

## ANTES DE IR

- [ ] Raio-X feito (5 min online)
- [ ] Print do GMB dele no celular
- [ ] Print de um GMB bom (exemplo)
- [ ] WhatsApp com foto profissional

---

## FLUXO (10 min no máximo)

### 1. CHEGADA (30s)
```
Bom dia! Sou o Guilherme, trabalho com presença digital aqui da
região. Posso falar 5 minutos com o dono?
```

### 2. DIAGNÓSTICO (2 min) — Ouve antes de falar
```
1. "Há quanto tempo com esse negócio?"
2. "Como chega cliente? Google ou indicação?"
3. "Quando alguém te procura no Google, te encontra?"
```

### 3. MOSTRAR O PROBLEMA (1 min)
```
Mostra o GMB dele vs. concorrente no celular.

"Olha: seu concorrente tem [fotos/avaliações/site]. Seu tá assim.
Quem te procura no Google e não te encontra, vai pra ele."
```

### 4. ENTREGAR RAIO-X (2 min)
```
"Fiz um raio-x rápido do teu negócio no digital. Tem 3 pontos
que tão fazendo você perder cliente sem saber."

[Mosta a página]

1. Google incompleto → cliente vai pro concorrente
2. [Problema específico dele]
3. [Problema específico dele]

"Isso não é crítico, mas é dinheiro saindo."
```

### 5. FECHAR (2 min)
```
"Resolvo isso por R$397 a 497. Completar o Google, fotos,
avaliações, tudo configurado. Posso começar essa semana?"
```

**Se disser "caro":**
```
"Entendo. Mas é investimento, não despesa. O Google traz cliente
novo sem tu fazer nada. E é preço fixo, não recorrente."
```

**Se disser "depois":**
```
"Sem problema. Mas o problema tá acontecendo agora. Cada dia sem
resolver é cliente que vai pro concorrente. Me chama quando quiser."
```

### 6. INDICAÇÃO (sempre)
```
"Valeu! Tem algum colega que tenha negócio parecido? Eu passo lá
e faço o raio-x pra ele também."
```

```
3. Combina prazo (2-5 dias)
```
