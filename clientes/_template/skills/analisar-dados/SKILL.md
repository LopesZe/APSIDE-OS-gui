# Skill: analisar-dados

# /analisar-dados — Análise de arquivos de dados

Analisa um arquivo de dados (CSV, Excel, TXT, JSON) e gera um resumo executivo com os principais insights, tendências e recomendações.

## Workflow

1. Receber arquivo (arrastar ou indicar caminho)
2. Detectar formato e estrutura
3. Analisar:
   - Volume de registros
   - Colunas e tipos
   - Dados faltantes
   - Estatísticas descritivas
   - Tendências e padrões
4. Gerar resumo executivo com:
   - Visão geral
   - Principais achados
   - Gráficos (quando aplicável)
   - Recomendações

## Regras

- Não alterar os dados originais
- Salvar análise em `saidas/`
- Insights acionáveis, não apenas descrições
