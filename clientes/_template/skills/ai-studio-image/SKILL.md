# /ai-studio-image — Gerar imagens via Google AI Studio

Gera imagens humanizadas via Google AI Studio (Gemini). Fotos realistas estilo bastidores/obra/produto com iluminação natural e imperfeições sutis.

## Dependências

- `GEMINI_API_KEY` no `.env`

## Workflow

1. Pedir descrição da imagem desejada
2. Montar prompt otimizado pra fotografia realista
3. Gerar via API do Gemini
4. Entregar imagem

## Regras

- Estilo fotográfico, não ilustração
- Iluminação natural
- Sem texto na imagem (legenda separada)
- Resolução adequada pra rede social
