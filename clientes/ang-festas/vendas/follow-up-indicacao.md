# Sistema de Follow-up e Indicação

> Cliente fechado não é fim. É começo. O follow-up gera indicação.
> A indicação gera cliente sem custo de prospecção.

---

## PARTE 1 — FOLLOW-UP PÓS-VENDA

### Dia 0 (dia do fechamento)
```
1. Registra em memoria/empresa.md: nome, contato, o que fechou
2. Manda WhatsApp: "Beleza [Nome], combinei [serviço]. Começo
   [amanhã/segunda]. Qualquer dúvida, me chama."
3. Cria pasta do projeto (se aplicável)
```

### Dia 3 (após entrega)
```
"Fala [Nome], tudo bem? Só queria saber se tá tudo certo com
[o que foi entregue]. Alguma dúvida?"
```

### Dia 7
```
"Nossa, uma coisa: você tem algum colega que tenha um negócio
parecido com o seu? Eu passo lá e faço um raio-x digital pra
ele também. Indicação é o melhor elogio."
```

### Dia 30
```
"Fala [Nome], já faz um mês. Como tão as coisas? Tá vindo mais
cliente pelo Google? Alguma mudança que tu percebeu?"
```

**Se tiver resultado:**
```
"Que bom! Uma coisa: se tu conhecer alguém que precise, me indica.
Eu trato igual você."
```

**Se não tiver resultado:**
```
"Deixa eu dar uma olhada. Às vezes precisa de um ajuste rápido.
Posso passar aí?"
```

## PARTE 2 — SISTEMA DE INDICAÇÃO

### Quando pedir
- **Sempre** no dia 7 pós-entrega
- Quando o cliente elogia o serviço
- Quando ele comenta que viu resultado
- Na renovação de contrato

### Script formal de indicação
```
[Nome], valeu demais pela confiança. Uma coisa que eu pediria:
se tiver algum colega seu — barbearia, restaurante, loja, clínica,
o que for — que precise melhorar a presença digital, fala de mim.

Eu passo lá, faço um raio-x digital gratuito, e se fizer sentido,
proponho uma solução. Sem compromisso pra ele.

E falo que foi você quem indicou, tá? Isso faz muita diferença.
```

### Se ele indicar
```
"Show! Me passa o nome e o contato que eu já entro em contato.
E falo que foi você quem indicou. Obrigado!"
```

### Registro da indicação
Anotar em `memoria/empresa.md`:
```
## Indicações recebidas
- [Nome do indicado] → indicado por [Nome do cliente] em [data]
  Status: [pendente / contatado / fechado / não fechado]
```

---

## PARTE 3 — RECONHECIMENTO

### Quando o cliente indica e fecha
```
Manda WhatsApp:
"[Nome], o [Nome do indicado] fechou! Valeu demais pela indicação.
Quando precisar de algo, é só chamar."
```

### Opcional: mimo
- Um agradecimento escrito ( WhatsApp mesmo)
- Prioridade no próximo atendimento
- Desconto de 10% no próximo serviço

**NÃO:**现金/brinde caro. Você é solo, não agência.

---

## PARTE 4 — REENGAJE (30-60-90 dias)

### 30 dias depois do último contato
```
"Fala [Nome], tudo bem? Já faz um tempo. Queria saber como tão
as coisas. Alguma novidade no negócio?"
```

### 60 dias
```
"[Nome], lembra que a gente fez [serviço]? Queria te mostrar
uma coisa nova que pode fazer sentido pra você. Posso te mandar?"
```

### 90 dias
```
"[Nome], já faz 3 meses. Se precisar de qualquer ajuste no
[o que foi feito], é só me chamar. Tô aqui."
```

## CRM MÍNIMO (planilha)

Use uma planilha com essas colunas:

| Nome | Negócio | Telefone | Data fechamento | Serviço | Valor | Status indicação | Próximo contato |
|------|---------|----------|-----------------|---------|-------|------------------|-----------------|
| João | Pet Shop X | (42) 99999-0000 | 10/09/2026 | Google | R$397 | Pendente | 17/09/2026 |

### Status indicação
- **Pendente** — ainda não pediu
- **Pedido** — pediu, esperando
- **Indicou** — indicou alguém
- **Fechou** — a indicação fechou

### Próximo contato
Sempre calcular: dia do fechamento + 7 dias = próximo follow-up

## FLUXO COMPLETO

```
FECHAMENTO
    │
    ├── Dia 0: confirma + registra
    ├── Dia 3: check-in
    ├── Dia 7: PEDIR INDICAÇÃO
    ├── Dia 30: medir resultado
    │
    └── Se indicou:
        ├── Contata indicado
        ├── Faz Raio-X
        ├── Fecha (ou não)
        └── Agradece ao cliente original
```

---

## REGRA

**Todo cliente que você entrega bem é um vendedor potencial.**

O custo de adquirir cliente por indicação é R$0.
O custo de prospecção é tempo + energia.

Invista no cliente que você já tem. Ele traz o próximo.
