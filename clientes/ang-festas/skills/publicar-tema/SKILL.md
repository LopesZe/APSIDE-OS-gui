# /publicar-tema — Conteúdo completo a partir de um tema

Orquestra a criação completa de uma peça de conteúdo SEO + redes sociais a partir de um tema.

## Dependências

- `memoria/empresa.md`
- `memoria/preferencias.md`
- `identidade/design-guide.md`

## Workflow

1. **Receber tema** (ou sugerir baseado na estratégia)
2. **Pesquisar** — usar WebSearch pra encontrar dados e referências
3. **Escrever artigo** — blog post completo (800-1200 palavras)
4. **Criar carrossel** — resumo do artigo em 5-8 slides
5. **Gerar legendas** — Instagram, Facebook, LinkedIn
6. **Salvar** — artefatos em `marketing/conteudo/insta-<tema>-<DATA>/`

## Regras

- Artigo com dados reais, não opinião
- Carrossel apontando pro blog (CTA)
- Legendas adaptadas por plataforma
- Tudo amarrado, mesmo idiomavisual
