# {{BUSINESS_NAME}} — Sistema Operacional

Sistema operacional do negócio de {{CLIENT_NAME}}.

## O que vem incluído

### Core (Governança)
Arquivos de governança do sistema:
- Regras, rotinas, roteamento de entradas, donos de verdade
- Tudo versionado no git como "sinal de vida"

### Memória
Sistema de memória persistente que o agente lê antes de cada resposta:
- Perfil do negócio
- Tom de voz e preferências
- Estratégia e prioridades

### Skills
Skills profissionais prontas:
- **GMB:** diagnóstico, comparativo, respostas, apresentação
- **SEO:** otimização local e geral
- **Conteúdo:** carrosséis, posts, blog
- **Visual:** geração de imagens com IA
- **Tráfego:** Google Ads, relatórios
- **Comunicação:** emails profissionais

### Site
Landing page Next.js com identidade visual customizada.

## Setup rápido

```bash
# 1. Instale dependências
cd site && npm install

# 2. Inicie o site
npm run dev
```

## Como usar

1. **`/abrir`** — carrega contexto no início da sessão
2. **`/salvar`** — versiona mudanças no git
3. **`/carrossel`** — cria carrosséis para Instagram
4. **`/diagnostico-gmb`** — analisa o Google Meu Negócio
5. **`/seo`** — otimiza para mecanismos de busca
