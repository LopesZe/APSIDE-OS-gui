## 2. MÉTODO — DO ZERO AO PRIMEIRO CLIENTE

### Passo 0 — Aprenda a ferramenta
- Instalar Claude Code + VS Code
- Não é preciso saber programar

### Passo 1 — Comece de graça
- Familiar/conhecido → criar case
- "Meus primeiros clientes eu peguei de graça."

### Passo 2 — Prospecção
- Boca a boca (gratuito)
- Outbound ativo (Google Maps)
- Inbound (funil + Instagram)

### Passo 3 — A call
- Chegar com trabalho pronto
- Ouvir 30 min sem falar nada
- Mostrar problema antes da solução
- Gravar e transcrever a call

### Passo 4 — Proposta
- Gerar PDF com Claude Code
- Diagnóstico completo da empresa

### Passo 5 — Entrega
- Entregar mais do que cobrou
- Cobrar setup inicial

## 4. TÉCNICAS DE VENDA

### Roteiro de call
1. Chegar com trabalho pronto
2. Ouvir 30 min
3. Mostrar problema
4. Demonstrar ferramenta
5. Fechar com pacote

### Regra de ouro
- "Se o seu cliente tiver resultado, ele vai te indicar para outras pessoas."
