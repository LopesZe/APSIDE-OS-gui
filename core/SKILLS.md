# SKILLS — Índice das skills

Procedimentos recorrentes do agente. Cada skill mora em `skills/<nome>/SKILL.md`.
O opencode descobre sozinho; este índice é para humanos e para o `RESOLVER.md`.

| Skill | O que faz |
|---|---|
| `/abrir` | Carrega a memória do negócio e devolve um resumo curto de onde paramos. |
| `/instalar` | Setup inicial: entrevista e preenche `memoria/*`, `identidade/`, `opencode.md`. |
| `/atualizar` | Varre o projeto e reconcilia os arquivos de contexto com o estado real. |
| `/salvar` | Commit + push no GitHub (sincronização do cérebro). |
| `/mapear-rotinas` | Mapeia tarefas repetitivas e cria skills personalizadas. |
| `/carrossel` | Cria carrosséis/visuais 1080×1350 (ou 1080×1440) com a identidade da marca. |
| `/post-instagram` | Posts/carrosséis IG: motivacional sem dopamina ou produto de uma marca/dia. |
| `/publicar-tema` | Conteúdo completo a partir de tema: blog + carrossel + legendas IG/FB/LinkedIn. |
| `/aprovar-post` | Aprova e publica (blog + Instagram + Facebook via Meta Graph API). |
| `/seo` | Fluxo completo SEO/GEO/Google Ads em 8 passos. |
| `/anuncio-google` | Campanha Google Ads em CSV pronto para o Google Ads Editor. |
| `/relatorio-ads` | Relatório semanal de Google + Meta Ads com alertas e recomendações. |
| `/responder-avaliacoes` | Respostas curtas e humanas para avaliações do Google Meu Negócio. |
| `/novo-projeto` | Cria pasta de projeto nova com `opencode.md` dedicado. |
| `/email-profissional` | Rascunha e-mail profissional a partir de contexto livre. |
| `/email-sequence` | Cria sequências de email B2B: prospecção, nutrição, boas-vindas, pós-venda. |
| `/analisar-dados` | Lê CSV/XLSX/PDF e gera resumo executivo com insights. |
| `/auditar` | Checa saúde do cérebro (memória/identidade/status) e atualiza `HEARTBEAT.md`. |
| `/ai-studio-image` | Gera imagens humanizadas via Google AI Studio (Gemini). |
| `/image-studio` | Gerador de imagens inteligente: fotos humanizadas + arte/edição. |
| `/growth-engine` | Estratégia de crescimento B2B: AARRR, SEO local, viral loops, referral. |
| `/apify-lead-generation` | Gera leads B2B via scraping: Google Maps, Instagram, Facebook. |
| `/content-creator` | Cria conteúdo com voz de marca: blog, social media, calendário editorial. |
| `/context-agent` | Continuidade entre sessões — salva resumos, decisões e pendências. |
| `/cred-omega` | Auditoria e governança de credenciais. |
| `/kpi-dashboard-design` | Dashboards de KPIs: métricas, visualização, monitoramento. |
| `/data-storytelling` | Transforma dados em narrativas: gráficos, apresentações, relatórios. |
| `/vender` | Script completo de venda presencial: Display → GMB → Site → Social. |
| `/prospecar` | Prospecção de clientes locais via Google Maps (scanner + score). |
| `/prospecar-instagram` | Prospecção via Instagram: perfis ativos sem site/GMB → leads qualificados. |
| `/proposta` | Gera proposta comercial com diagnóstico, soluções e preços. |
| `/diagnostico-gmb` | Diagnóstico completo do Google Meu Negócio com score 0-100. |

> Toda skill nova segue o template em `templates/skills/skill-template.md`.
