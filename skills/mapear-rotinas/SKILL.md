# /mapear-rotinas — Criar skills personalizadas

Mapeia tarefas repetitivas que o usuário faz no dia a dia e gera skills personalizadas pra automatizá-las.

## Workflow

1. **Entrevista** — perguntar:
   - O que você repete toda semana?
   - Quais tarefas tomam mais tempo?
   - Tem alguma sequência de passos que você sempre segue?

2. **Analisar** — identificar padrões repetíveis

3. **Propor** — sugerir 1-3 skills concretas com nome, trigger e workflow

4. **Criar** — pra cada skill aprovada:
   - Criar pasta `skills/<nome-da-skill>/`
   - Criar `SKILL.md` seguindo o template em `templates/skills/skill-template.md`
   - Atualizar `SKILLS.md` e `RESOLVER.md`

## Regras

- Só criar skills pra tarefas realmente repetíveis (3+ vezes)
- Perguntas claras e objetivas
- Não criar skill pra coisa pontual
