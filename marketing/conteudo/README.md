# Conteúdo gerado

Conteúdo produzido pelas skills de conteúdo (carrossel, post-instagram, publicar-tema, etc).

## Organização

Cada peça de conteúdo deve ficar em uma pasta:

```
insta-<tema>-YYYY-MM-DD/
├── carrossel.html      # HTML do carrossel
├── instagram/          # PNGs renderizados
│   ├── slide-01.png
│   ├── slide-02.png
│   └── ...
└── legenda.md          # Legenda pra publicar
```
