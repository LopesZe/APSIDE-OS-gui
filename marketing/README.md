# Marketing

Pasta pra todo conteúdo de marketing do negócio.

## Estrutura

- **`conteudo/`** — Conteúdo gerado (posts, carrosséis, artigos, legendas)
- **`templates/`** — Templates de conteúdo (carrossel, post, story, legenda)
- **`ideias/`** — Referências visuais, screenshots, links de inspiração
- `estudo-gmb.*` — Estudo completo sobre Google Meu Negócio
- `render-estudo.cjs` — Script de render do estudo GMB

## Como usar

- Salve conteúdo gerado pelas skills em `conteudo/`
- Organize por data: `<tipo>-<tema>-YYYY-MM-DD/`
- Cada pasta de conteúdo deve ter: carrossel HTML, PNGs renderizados, legenda
- Referências de inspiração em `ideias/`
- Templates em `templates/`

## O que NÃO está aqui

- **Análises (raiox, diagnósticos, SEO, YouTube)** → `analise/`
- **Propostas e documentos de saída** → `saidas/`
- **Dados brutos para análise** → `dados/`
