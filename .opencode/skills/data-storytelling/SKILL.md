# Skill: data-storytelling

# /data-storytelling — Transformar dados em narrativas

Transforma dados em narrativas compreensíveis usando visualização, contexto e estrutura persuasiva.

## Workflow

1. Receber dados (arquivo ou contexto)
2. Identificar a história por trás dos números
3. Estruturar narrativa:
   - Contexto (situação atual)
   - Conflito (problema/desafio)
   - Resolução (solução/recomendação)
4. Criar visualizações quando aplicável
5. Entregar relatório executivo

## Regras

- Dados primeiro, história depois
- Nunca distorcer números pra caber na narrativa
- Visualizações claras e simples
