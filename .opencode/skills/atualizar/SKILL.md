# Skill: atualizar

# /atualizar — Reconciliação de contexto

Varre o projeto e atualiza os arquivos de contexto (`memoria/empresa.md`, `preferencias.md`, `estrategia.md`, `opencode.md`, `identidade/design-guide.md`) que ficaram desatualizados em relação ao estado real do workspace.

## Workflow

1. Ler todos os arquivos de contexto
2. Confrontar com o estado real do workspace (arquivos existentes, skills criadas, etc.)
3. Identificar inconsistências (ex: skill criada mas não listada no `SKILLS.md`)
4. Propor correções ao operador
5. Aplicar as aprovadas

## Regras

- Não alterar sem perguntar
- Mostrar o que vai mudar antes de aplicar
- Só sugerir mudanças baseadas em evidências reais
