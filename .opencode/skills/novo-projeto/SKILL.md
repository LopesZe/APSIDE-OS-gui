# /novo-projeto — Criar pasta de projeto

Cria uma pasta de projeto nova com `opencode.md` dedicado, depois de uma entrevista curta sobre o projeto (cliente, objetivo, entregas previstas).

## Workflow

1. Perguntar: nome do projeto, cliente, objetivo, entregas previstas
2. Criar pasta `projetos/<nome-do-projeto>/`
3. Criar `opencode.md` dentro com contexto específico do projeto
4. Confirmar criação

## Regras

- Nome da pasta em minúsculo, sem acento, separado por hífens
- `opencode.md` do projeto herda as regras gerais do root
- Não duplicar informações que já existem no contexto geral
