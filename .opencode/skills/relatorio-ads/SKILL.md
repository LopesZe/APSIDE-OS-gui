# /relatorio-ads — Relatório de performance de anúncios

Gera relatório semanal de performance de anúncios pagos (Google Ads + Meta Ads). Lê dados e devolve análise executiva com KPIs, alertas e recomendações.

## Workflow

1. Pedir dados (CSV, prints ou acesso às plataformas)
2. Analisar KPIs: impressões, cliques, CTR, CPC, conversões, ROAS
3. Identificar alertas: queima de orçamento, CTR baixo, conversões caindo
4. Gerar relatório com:
   - Resumo executivo
   - Top criativos
   - Alertas
   - Recomendações práticas pra semana seguinte

## Regras

- Linguagem direta, sem rodeios
- Priorizar ações corretivas
- Comparar com semana anterior quando possível
