# SCRIPT DE VENDA PRESENCIAL — BASEADO EM PROBLEMA

> Fluxo completo: da chegada ao fechamento.
> Funciona pra: pet shop, restaurante, salão, clínica, oficina, loja, escritório, escola...
> O cliente compra a resolução de um problema, não um produto.

---

## OBJETIVO DE CADA ABORDAGEM

```
Mínimo: Raio-X entregue (diagnóstico gratuito)
Ideal: Problema identificado + proposta feita
Desejável: Projeto fechado
```

**Regra de ouro:** O diagnóstico é a porta. Não o Display NFC.

---

## ANTES DE SAIR DE CASA

### Preparação:
- Raio-X Digital já feito pra cada negócio (5-10 min online)
- Celular com print de **GMB bem feito** (exemplo de resultado)
- WhatsApp com foto profissional + nome salvo

### Pesquisa prévia (5-10 min por cliente):
- Nome completo do negócio no Google
- Se tem GMB (se não tem = oportunidade pura)
- Se tem site (se não tem = oportunidade)
- Nome do dono (Instagram, Google, placa na frente)
- Horário de funcionamento

### O que procurar na pesquisa:
- Google incompleto? → oportunidade
- Muitas avaliações sem resposta? → oportunidade
- Instagram forte mas sem conversão? → oportunidade
- Negócio bom + presença digital ruim? → oportunidade perfeita

---

## FLUXO GERAL

```
CHEGADA (porta/recepção)
        │
        ├── Dono não está ──→ Deixa cartão + mensagem
        │
        └── Dono está ──→ Conversa
                │
                ├── Ele não quer conversar ──→ Agradece e sai
                │
                └── Ele ouve ──→ Fase 1: DIAGNÓSTICO
                        │
                        └── Fase 2: MOSTRAR PROBLEMA
                                │
                                └── Fase 3: ENTREGAR VALOR
                                        │
                                        └── Fase 4: FECHAR
                                                │
                                                └── Fase 5: PEDIR INDICAÇÃO
```

---

## FASE 1 — CHEGADA (primeiros 30 segundos)

### O que NÃO fazer:
- Chegar falando "bom dia, eu vendo..."
- Chegar com cara de vendedor
- Falar rápido e empurrar

### O que fazer:
- Chegar com calma, sorriso aberto
- Cumprimentar naturalmente
- Pedir permissão pra falar

### Script de chegada:
```
Bom dia! Tudo bem? Sou o Guilherme, trabalho com presença digital
aqui da região. Posso falar 5 minutos com o dono?
```

### Se ele disser "eu sou o dono":
```
Show! [NOME DO DONO], prazer. Tô passando aqui porque ajudo
negócios locais a aparecerem mais no Google. Posso mostrar
uma coisa rápida?
```

### Se ele disser "não sou o dono":
```
Sem problemas! Será que tem como me passar o contato do dono?
Ou se ele tiver aqui, posso falar com ele rapidinho?
```

---

## FASE 2 — DIAGNÓSTICO (primeiro minuto)

### Regra: ouça 2 minutos antes de falar.

### Pergunta 1 — Abertura:
```
[NOME], quanto tempo você tá com esse negócio aqui?
```

### Pergunta 2 — Contexto:
```
E como tá a questão de clientela? Tá vindo bastante gente pelo
Google ou mais por indicação?
```

### Pergunta 3 — Dor (a mais importante):
```
E quando o cliente chega aqui, ele já te conhece ou chega
falando "achei você no Google"?
```

### Pergunta 4 — Conexão:
```
Entendi. E vocês têm algum tipo de presença online? Site, Instagram,
Google Meu Negócio?
```

### NÃO fale de produto ainda. Escute. Anote mentalmente.

### O que procurar enquanto ouve:
- Ele tem GMB? → Se não tem, é oportunidade pura
- Ele tem site? → Se não tem, oportunidade
- Ele reclama de poucos clientes? → Dor pronta
- Ele reclama de concorrência? → Dor pronta
- Ele fala "meu concorrente tá aparecendo mais"? → Dor pronta

---

## FASE 3 — MOSTRAR O PROBLEMA (o momento decisivo)

### Depois de ouvir, ele vai te perguntar: "então, o que você faz?"

### Resposta (não fale de produto, fale de PROBLEMA):
```
Olha, eu vou te mostrar uma coisa rápida. Posso pegar teu
celular ou mostrar no meu?
```

### Mostra o GMB dele no celular (ou o print que você trouxe):
```
Olha só. Quando alguém busca "[nicho] perto de mim" no Google,
olha quem aparece primeiro... [mostra concorrente]
E olha o teu... [mostra o GMB dele]
```

### Frase-chave (sem inventar números):
```
Hoje seu concorrente tem um perfil mais completo, mais avaliações
e mais informações pra quem tá pesquisando. Isso pode influenciar
qual empresa a pessoa escolhe.
```

### Conectar com o que ele falou:
```
[NOME], você falou que a maioria dos clientes vem por indicação.
Isso é bom. Mas quem te procura no Google e não te encontra,
vai direto pro concorrente.
```

### NÃO fale de solução ainda. Deixe o problema afundar.

---

## FASE 4 — ENTREGAR VALOR (o raio-x)

### Só depois de mostrar o problema, ofereça o diagnóstico:

### Passo 1 — O gancho:
```
Olha, eu fiz um raio-x rápido do teu negócio no digital. Google,
site, redes, como tu capta cliente. Encontrei 3 pontos que
provavelmente estão fazendo vocês perderem oportunidades.
```

### Passo 2 — Mostrar (1 página, rápido):
```
[Mostra o raio-x de 1 página]

1. Seu Google tá incompleto — sem foto de capa, avaliações sem
   resposta. Isso afeta direto quem te busca.

2. Você depende de indicação — quem te procura no Google e não
   te encontra, vai pro concorrente.

3. [Terceiro problema específico do negócio]

Isso não é crítico, mas é dinheiro que tá saindo do teu bolso
sem tu saber.
```

### Passo 3 — Silêncio. Espera ele falar.

### Se ele perguntar "e como resolve?":
```
Depende do que fizer mais sentido. Uma opção é começarmos pelo
Google — completar o perfil, colocar fotos, organizar as
avaliações. Uma coisa que eu faço é entregar isso em 2-5 dias.

Mas antes de te dar um preço, preciso entender melhor a situação.
Posso te ligar amanhã pra gente conversar 15 minutos?
```

### Se ele disser "ah, mas eu já tenho avaliações":
```
Que ótimo! Mas a pergunta é: quantas avaliações você recebe
por mês? Se tiver menos de 10, isso pode estar limitando
o quanto o Google mostra seu negócio.
```

### Se ele disser "não tenho Google":
```
Aí é ainda melhor! O Google Meu Negócio é grátis — o que eu
faço é deixar ele completo e bonito, pra quando alguém buscar,
você aparecer.
```

---

## FASE 5 — FECHAR (ou agendar)

### Se ele topou conversar:
```
Beleza, [NOME]. Te ligo amanhã pra gente conversar 15 minutos.
É só pra eu entender melhor a situação e te passar uma proposta
que faça sentido. Posso ligar por volta das [HORÁRIO]?
```

### Se ele topou na hora:
```
Show! Só preciso de umas informações básicas pra começar.
[Nome do negócio no Google, horário, WhatsApp]
```

### Silêncio depois do preço. Quem fala primeiro perde.

### Se ele disser "tá caro":
```
Entendo. Mas olha: resolver o problema do Google não é despesa,
é investimento. É o que traz cliente novo sem tu fazer nada.
E o preço é fixo, não recorrente.
```

### Se ele disser "depois eu penso":
```
Sem problema. Só que o problema que eu te mostrei tá acontecendo
agora. Cada dia sem resolver é cliente que vai pro concorrente.
Quando quiser resolver, é só me chamar.
```

### Se ele disser "meu sobrinho faz":
```
Beleza, se ele souber fazer certo. Só que o Google exige umas
coisas específicas — fotos certas, serviços categorizados,
resposta de avaliação no padrão. Se não fizer certo, não aparece.
```

---

## FASE 6 — PEDIR INDICAÇÃO (sempre no final)

### Quando ele ficar satisfeito:
```
[NOME], valeu demais! Uma coisa: se tiver algum colega seu que
tenha um negócio parecido — barbearia, restaurante, loja, o que
for — fala de mim. Eu passo lá e faço um raio-x digital pra ele
também. Indicação é o melhor elogio que eu receberia.
```

### Se ele indicar:
```
Show! Me passa o nome e o contato que eu já entro em contato.
E falo que foi você quem indicou, tá? Isso faz muita diferença.
```

Vai com calma, mas vai. Cada negócio que você entra é um passo à frente.
