# Template de Skill

Copie este arquivo para `skills/<nome-da-skill>/SKILL.md` e preencha.
Toda skill é um **procedimento recorrente** com gatilho, objetivo, passos e validação.

# Skill: <nome>

# /<nome> — <título curto>

## Gatilho
Frases/comandos que devem disparar esta skill. (Espelhar também em RESOLVER.md.)

## Objetivo
O que a skill entrega, em 1–2 linhas.

## Passos
1. ...
2. ...
3. ...

## Como validar
Como confirmar que deu certo (ex.: arquivo criado, comando rodou, link respondeu).

## Notas
Caminhos de apoio, exemplos, armadilhas conhecidas.

Regras:
- Nome de arquivo sempre `SKILL.md` dentro de `skills/<nome>/`.
- Use os arquivos de contexto do OS (`memoria/`, `identidade/`, `MAPA.md`,
  `PROPAGATION.md`) como referência, não duplique neles.
- Se a skill precisar de arquivos de apoio (templates, exemplos), crie dentro da
  própria pasta da skill.
