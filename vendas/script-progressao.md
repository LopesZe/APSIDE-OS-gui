# PROGRESSÃO DE CLIENTE — Confiança antes de escala

> Cada entrega gera confiança. Cada confiança abre porta pra problema maior.
> Nunca forçar upsell. Criar terreno fértil.

---

## PRINCÍPIO CENTRAL

O cliente não precisa passar por todas as etapas. Cada cliente segue o caminho correspondente ao problema que possui.

```
Cliente A: Google → R$397 → fim.
Cliente B: Google + landing → R$997.
Cliente C: Google + site + captação → R$2.500.
Cliente D: Diagnóstico → CRM + automação → R$6.000.
```

---

## COMO EVOLUIR UM CLIENTE

### PASSO 1 — Entregar bem o pequeno

Se fechou R$297-497 (Google), entregar com qualidade:
- Perfil completo
- Fotos profissionais
- Avaliações respondidas
- Display NFC configurado (se fizer sentido)

Mostrar resultado real. Gerar confiança.

### PASSO 2 — Monitorar (30 dias depois)

Depois de 30 dias, perguntar:
```
[NOME], como tá as coisas? Tá vindo mais cliente pelo Google?
```

**Se sim:**
```
Bom. E como tá a parte de converter quem te encontra?
Tu tem site? Onde o cliente vai quando clica no teu perfil?
```

**Se não:**
```
Deixa eu ver o que pode estar acontecendo...
[analisa novamente e identifica o que falta]
```

### PASSO 3 — Conectar o próximo problema

Depois de ouvir, conectar com o que faz sentido:

**Exemplo 1 — Google funcionando, mas sem conversão:**
```
O Google tá funcionando, mas quem te encontra não tem como
te chamar facilmente. Tu tem site?
```

**Exemplo 2 — Muitos leads, atendimento manual:**
```
Tu tá recebendo mensagem no WhatsApp mas não tem como
organizar isso, né? É muita mensagem, perde contato,
esquece de responder...
```

**Exemplo 3 — Empresa crescendo, processos manuais:**
```
Tu tá crescendo, mas a parte de atendimento tá no improviso.
Isso funciona com 5 clientes, mas com 20 vai ter problema.
```

### PASSO 4 — Propor o próximo passo

Não como "mais um serviço", mas como "próximo passo lógico":

```
Agora que o Google tá trazendo gente, quer que eu monte
uma página pra converter essas visitas em cliente?
```

```
Tu tá recebendo lead mas perdendo. Quer que eu monte
um sistema básico pra organizar isso?
```

### PASSO 5 — Repetir o ciclo

Cada entrega gera confiança. Cada confiança abre porta pra problema maior. Nunca pular degraus.

---

## EXEMPLO REAL DE PROGRESSÃO

```
Mês 1: Google (R$397) → cliente satisfeito
Mês 2: "Quer uma página?" → Landing Page (R$997)
Mês 3: "Tá recebendo lead mas perdendo?" → Organização básica (R$1.500)
Mês 4: "Quer automatizar o atendimento?" → Automação (R$3.000+)
```

**Não acontece com todo cliente. Alguns ficam só no Google. E tá tudo bem.**

---

## QUANDO NÃO EVOLUIR

- Cliente satisfeito com o que tem → não insistir
- Cliente sem orçamento → esperar
- Cliente que não vê problema → não forçar
- Cliente que quer "só postar" → não é cliente ideal

---

## REGRA DE OURO

**A cada entrega, perguntar:**
1. O cliente tá satisfeito?
2. Tem algum problema novo que apareceu?
3. Faz sentido eu resolver isso?

Se 3 de 3 forem "sim", é hora de propor o próximo passo.

Se qualquer um for "não", esperar.
