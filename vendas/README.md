# Vendas

Scripts, roteiros e materiais de venda. Tudo consolidado aqui.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `script-rapido.md` | Script de 1 página (imprimir e levar no bolso) |
| `script-venda-presencial.md` | Roteiro completo de abordagem presencial |
| `script-progressao.md` | Como evoluir de cliente pequeno pra projeto maior |
| `roteiro-abordagem.md` | Templates de abordagem (LinkedIn, Instagram DM, WhatsApp) |
| `escada-precos.md` | Faixas de preço por tipo de problema |
| `prospecacao-digital.md` | Templates de prospecção digital |
| `follow-up-indicacao.md` | Cronograma pós-venda + sistema de indicação |

## Como usar

- A skill `/vender` referencia estes arquivos para montar o fluxo de venda
- Para impressão rápida: `script-rapido.md`
- Para visita presencial completa: `script-venda-presencial.md`
- Para evolução de cliente: `script-progressao.md`
